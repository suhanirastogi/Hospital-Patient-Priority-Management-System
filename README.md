A C++ console-based hospital management application that organizes patient records and waiting lists using fundamental Data Structures.
Features
- Add new patients
- Assign emergency priorities
- Call the next patient
- Search patients using Patient ID
- Display waiting lists
- Cancel patient registrations
- Check patient status
- View hospital statistics
Data Structures Used
- Priority Queue: Emergency patient management
- Queue: Normal patient management (FIFO)
- Linked List: Patient record storage
- Hashing: Fast patient searching using Patient ID
Technologies Used
- C++
- Data Structures and Algorithms
- CodeBlocks / Visual Studio
Priority Levels
1. Normal
2. Low Emergency
3. Medium Emergency
4. High Emergency
5. Critical Emergency
How to Run
1. Clone this repository.
2. Open the .cpp file in CodeBlocks or Visual Studio.
3. Compile and execute the program.
Project Objective
To demonstrate the practical application of fundamental data structures in a real-world hospital patient management scenario.
